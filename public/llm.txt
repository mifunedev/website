# Mifune — AGRO workspaces for coding agents

> A portable home for autonomous coding agents.

## Category and value

AGRO is coding-agent workspace infrastructure: one repository connects to an isolated, persistent workspace for its coding agents. It keeps project toolchains off the host. Workspaces run on a laptop, a remote VM, or a Mifune Console node; Docker is one supported runtime.

Bring your preferred coding agent. AGRO supports Claude Code, Codex, Pi, OpenCode, Hermes, OpenClaw, Grok Build, Muse Code, Antigravity CLI, and fx, and two or more can run side by side in one workspace. On a VM, agents can work unattended or on schedules and can be reachable over Slack. Isolated git worktrees support parallel branches and delegation.

Grounded outcomes:

- Isolate each project in its own workspace.
- Keep project toolchains off the host or laptop.
- Run the workspace locally or on a remote VM.
- Separate parallel branches with isolated git worktrees.

## Vendor

Mifune maintains the Apache-2.0 licensed open-source AGRO project, operates the Mifune Console as the managed path, and offers forward-deployed engineering support to Console customers.

## Offering hierarchy

### 1. Mifune Console — recommended managed path

The Mifune Console gives coding agents an isolated, persistent workspace while Mifune operates the managed environment.

- Mifune Console: https://console.mifune.dev
- Pricing: https://mifune.dev/pricing

Nodes run from prepaid credit, each on a dedicated VM rather than shared infrastructure. Compute bills per second, with a minimum of 60 seconds for each run. Storage for the node volumes bills for each started clock hour while the node runs. Queued, building, and failed time is free. The storage price covers the included data disk of each size. A larger data disk comes in steps of 10 GB, up to 500 GB. Extra disk costs 0.14 USD per GB-month, billed for each started hour while the node runs, on every node with a data volume; on a free node, the included disk stays free and extra disk bills from prepaid credit. Credit comes in top-ups of 25, 50, or 100 USD, with an optional automatic top-up in the same amounts. When the balance covers less than 24 hours of spend, the org admins get an email; a negative balance starts a 24-hour grace window, and running paid nodes pause at its end. Pausing a node stops the running charge and keeps /home/sandbox, where the repositories live; it does not keep running processes, memory, or Docker volume data. Each paid node gets 3 free paused days per UTC calendar month, summed across all its pauses that month; a new pause does not restart the free days. After the free days, a paused paid node pays 0.14 USD per GB-month for its whole disk, prorated per second, until it is resumed or destroyed; each billable paused second bills once. With the included disk, the paused price is $2.80 a month for n2 and $3.50 a month for n4 to n64. A disposable hand costs less: it has no data volume, so it pays only a boot storage fee of about 0.003 USD for each started hour on top of compute. A disposable hand cannot pause or fork, and the Console deletes it at the end of the grace window or when the free allowance runs out. Destroying a node deletes it. Each node opens in the browser with a terminal and an editor, and needs no SSH key. AI usage is not included: you sign in to each agent CLI you use, such as Claude Code, Codex, Pi, OpenCode, Hermes, or any other supported harness, inside the workspace with your own account and pay that provider directly. Mifune holds no model credential and does not mark up tokens.

Hourly rates: compute bills per second with a 60-second minimum for each run, and storage bills for each started clock hour while the node runs:

- 2 GB (1 vCPU / 2 GB RAM / 20 GB SSD): compute $0.0230 per hour, storage $0.0080 per started hour, $0.0310 per full running hour
- 4 GB (2 vCPU / 4 GB RAM / 25 GB SSD): compute $0.0450 per hour, storage $0.0090 per started hour, $0.0540 per full running hour
- 8 GB (4 vCPU / 8 GB RAM / 25 GB SSD): compute $0.0800 per hour, storage $0.0090 per started hour, $0.0890 per full running hour
- 16 GB (4 vCPU / 16 GB RAM / 25 GB SSD): compute $0.2100 per hour, storage $0.0090 per started hour, $0.2190 per full running hour
- 32 GB (8 vCPU / 32 GB RAM / 25 GB SSD): compute $0.4200 per hour, storage $0.0090 per started hour, $0.4290 per full running hour
- 64 GB (8 vCPU / 64 GB RAM / 25 GB SSD): compute $0.5400 per hour, storage $0.0090 per started hour, $0.5490 per full running hour

A personal free tier gives two n2 or n4 nodes that share 24 running hours per UTC month, with no card; the nodes auto-pause at the limit and each workspace is kept 14 days after each pause. Free spots are limited, and a paid node runs from prepaid credit. There is no monthly plan.

Each org can run 10 paid nodes by default. To request more, email support@mifune.dev. The free-tier limits are separate.

A node left running for a whole month pays compute for 730 hours and storage for 730 started hours at the rates above, which works out to:

- 2 GB: about $22.63 for 730 running hours — an estimate from the hourly rate, not a monthly plan
- 4 GB: about $39.42 for 730 running hours — an estimate from the hourly rate, not a monthly plan
- 8 GB: about $64.97 for 730 running hours — an estimate from the hourly rate, not a monthly plan
- 16 GB: about $159.87 for 730 running hours — an estimate from the hourly rate, not a monthly plan
- 32 GB: about $313.17 for 730 running hours — an estimate from the hourly rate, not a monthly plan
- 64 GB: about $400.77 for 730 running hours — an estimate from the hourly rate, not a monthly plan

Those are arithmetic on the hourly rate for a node that never stops; a node that runs only on weekdays costs proportionally less, and there is no monthly plan to buy at any usage.
