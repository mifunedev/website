# Mifune — AGRO workspaces for coding agents

> A portable home for autonomous coding agents.

## Category and value

AGRO is coding-agent workspace infrastructure: one repository connects to an isolated, persistent Docker workspace for its coding agents. It keeps project toolchains off the host and runs locally or on a remote VM.

Bring your preferred coding agent. AGRO supports Claude Code, Codex, Pi, and other opt-in agent CLIs. On a VM, agents can work unattended or on schedules and can be reachable over Slack. Isolated git worktrees support parallel branches and delegation.

Grounded outcomes:

- Isolate each project in its own workspace.
- Keep project toolchains off the host or laptop.
- Run the workspace locally or on a remote VM.
- Separate parallel branches with isolated git worktrees.

## Vendor

Mifune maintains the Apache-2.0 licensed open-source AGRO project, operates the Mifune Cloud Console as the managed path, and offers forward-deployed engineering support to Console customers.

## Offering hierarchy

### 1. Mifune Cloud Console — recommended managed path

The Mifune Cloud Console gives coding agents an isolated, persistent workspace while Mifune operates the managed environment.

- Cloud Console: https://console.mifune.dev
- Pricing: https://mifune.dev/pricing

Nodes are billed by the hour they run, each on a dedicated VM rather than shared infrastructure. Only whole running UTC hours meter; queued, building, and failed time is free. Pausing a node stops billing and keeps its workspace; destroying a node deletes it. Each node opens in the browser with a terminal and an editor, and needs no SSH key. AI usage is not included: you sign in to Claude, Pi, or another opt-in agent CLI inside the workspace with your own account and pay that provider directly.

Hourly rates, per whole hour a node is running:

- 4 GB (2 vCPU / 4 GB RAM / 50 GB SSD): $0.0450
- 8 GB (4 vCPU / 8 GB RAM / 50 GB SSD): $0.1000
- 16 GB (4 vCPU / 16 GB RAM / 100 GB SSD): $0.2100
- 32 GB (8 vCPU / 32 GB RAM / 200 GB SSD): $0.4500
- 64 GB (8 vCPU / 64 GB RAM / 200 GB SSD): $0.6000

A personal free tier gives one n4 node 24 running hours per UTC month with no card; the node auto-pauses at the limit and its workspace is kept 60 days after each pause. Free spots are limited, and a paid node needs a card. There is no monthly plan.

A node left running for a whole month is billed as 730 whole hours at the rate above, which works out to:

- 4 GB: about $32.85 for 730 running hours — an estimate from the hourly rate, not a monthly plan
- 8 GB: about $73.00 for 730 running hours — an estimate from the hourly rate, not a monthly plan
- 16 GB: about $153.30 for 730 running hours — an estimate from the hourly rate, not a monthly plan
- 32 GB: about $328.50 for 730 running hours — an estimate from the hourly rate, not a monthly plan
- 64 GB: about $438.00 for 730 running hours — an estimate from the hourly rate, not a monthly plan

Those are arithmetic on the hourly rate for a node that never stops; a node that runs only on weekdays costs proportionally less, and there is no monthly plan to buy at any usage.

### 2. AGRO Open Source — self-hosted path

The Apache-2.0 licensed project is for teams that want to inspect, adapt, and operate AGRO themselves, locally or on a remote VM.

- GitHub: https://github.com/mifunedev/agro
- Documentation: https://agro.mifune.dev

Mifune engineers can work alongside a Console customer's team to plan, implement, integrate, troubleshoot, and hand off a Mifune Cloud Console deployment. An established deployment is not required before discussing a scope.
